# TatRaksha: submission pack (Track 5)

## Product description (2–3 lines)

> **TatRaksha turns an IMD cyclone bulletin into village-level action 72 hours before landfall.** Gemini 3.7 Flash
> reads the bulletin and the hazard map, screening surge and rainfall-flood models rank every village, and
> flood-aware routing shows which shelters get cut off. District officers approve CAP 1.2 advisories in Odia,
> Bengali and English with voice, and the State EOC compares districts and sees parametric trigger estimates.

**"N integrations live"** badge once so you know what is live (Gemini, Maps Routes, Translation, TTS, STT,
BigQuery, Cloud Storage). Screen 1440×900, browser zoom 90 %.
